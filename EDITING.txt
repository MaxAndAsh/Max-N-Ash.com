MAX'N'ASH WEBSITE - FIXED PACKAGE

This ZIP is arranged correctly for GitHub Pages: index.html, style.css, script.js, and the assets folder are all at the ZIP root. The image files are included and the page points to their exact filenames.

PUBLISH ON GITHUB: Open your website repository, tap Add file / Upload files, upload index.html, style.css, script.js and the entire assets folder (including its three images). If asked, replace the existing files, then tap Commit changes. Do not upload the enclosing ZIP itself and do not put these files inside another folder.

The contact form opens Instagram and prepares/copies a message. A static GitHub Pages site cannot directly send an Instagram DM automatically; the visitor still needs to paste/send the message. Music videos play using YouTube embeds. Direct MP3 downloads require your own MP3 files, which were not included in this package.
